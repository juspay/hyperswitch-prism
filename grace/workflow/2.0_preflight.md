# Preflight Agent

You are stage **S0** of a GRACE v2 connector run (`grace/workflow/2_connector.md`). You make one Linux host fit for a
long multi-unit run of **{CONNECTOR}**: tools and GitHub access, credentials in the shape the harness accepts, a clean
UCS tree on the run branch, enough free disk (deleting only provably stale `target/` dirs), free ports, the Hyperswitch
(HS) checkout state plus an HS worktree, and background warm builds that compile while S1–S3 run.

You edit no repo file, so you append nothing to `{RUN_DIR}/claimed.tsv`. The orchestrator re-spawns you with
`MODE=DISK_ONLY` for its disk guard before S4, S4z and each S5 build.

## RULES

1. **Linux only, autonomous.** GNU coreutils, `/proc`, `ss`, `flock`. Never ask; every judgement call is a row in the
   decisions file.
2. **Abort cleanly.** A block that prints `ABORT_*` ends the phases: go to Phase 10, write the decisions file and the
   output with `abort` set, start no background build, return that status. Unexpected failures (fetch, no free port) → `FAILED`.
3. **Git.** Allowed: `fetch`, `switch` to the run branch, `worktree add` in HS. Forbidden: commit, push, stash, reset,
   `checkout -f`, clean, restore. Never modify the creds file or any tracked file.
4. **Deletion.** Only `rm -rf -- <target dir>` of a target classified `ELIGIBLE_*` and re-classified immediately
   before the `rm`. Never delete a target tracked in git, or a target of: a dirty checkout (untracked counts), a checkout with a live process
   (`/proc/*/cwd` or `/proc/*/exe` inside it), a held `.cargo-lock`, a dir you do not own, another filesystem, the UCS
   root checkout (nested targets included), `{HS_REPO_PATH}`, `grace/runs/**`, `$CARGO_TARGET_DIR`. Those are listed only.
5. **Processes.** Kill nothing but a `long` job past its cap (Phase 9 detached-job contract): grpc-servers are listed
   (Phase 6) and busy ports skipped (2_connector.md R12).
6. **Secrets.** Never write a credential value, a token, or `/proc/<pid>/environ` content other than the one matched
   UCS `base_url` variable. Record paths, shapes and variable names only.
7. **Shell state.** Bash state does not persist between calls: every block starts with
   `. {SCRATCH}/vars.sh` (Phase 5 onward also `. {SCRATCH}/lib.sh`) and appends what it computes as `KEY='value'`.
   The blocks below leave that preamble implicit — a detached script sources both itself, since it inherits nothing.
   Commands run from the repo root.
8. **Idempotent.** A crash re-spawn reuses the run branch, the worktree and a live warm pid. No AMEND mode: `FULL` runs
   once per run (resume skips S0 when `preflight.json` exists).

## Phase 0: Setup

`{SCRATCH}` = `{RUN_DIR}/.preflight` (`FULL`) or `{RUN_DIR}/disk/.{DISK_TAG}` (`DISK_ONLY`). Bind every input,
leaving `MIN_FREE_GB` / `MIN_FREE_GB_RUNTIME` empty when not given, `PARALLEL_HS_BUILD` to its default and `STALE_DAYS` to 3
when empty or not a positive integer (fail closed: `0` would make every clean target idle). A crash
re-spawn keeps the existing `vars.sh` (it holds `PRE_SWITCH_SHA`, which Phase 3 must not recompute after Phase 7).

Create `SCR` = `{SCRATCH}`, plus `{RUN_DIR}/warm` and `{RUN_DIR}/disk`. `RUN` = `{RUN_DIR}` without its trailing `/`,
`UCS_ROOT` = `git rev-parse --show-toplevel`, `RUN_ID` = `basename "$RUN"`, `RUN6` = its `-` suffix,
`CONNECTOR_LC` = `{CONNECTOR}` lowercased — `FAILED: RUN_DIR does not match connector` when `RUN_ID` is not
`<connector_lc>-<run6>`. `HS` = `{HS_REPO_PATH}` through `realpath -m` when non-empty (absolute; it is recorded as
`hs.path` and every later `git -C` uses it). Then:

```bash
[ -f "$SCR/vars.sh" ] || cat > "$SCR/vars.sh" <<EOF
RUN='$RUN'; RUN_ABS='$UCS_ROOT/$RUN'; UCS_ROOT='$UCS_ROOT'; RUN_ID='$RUN_ID'; RUN6='${RUN_ID##*-}'
CONNECTOR_LC='$CONNECTOR_LC'; HS_REPO_PATH='$HS'; MODE='{MODE}'; STALE_DAYS='{STALE_DAYS}'
MIN_FREE_GB='{MIN_FREE_GB}'; MIN_FREE_GB_RUNTIME='{MIN_FREE_GB_RUNTIME}'; PARALLEL_HS_BUILD='{PARALLEL_HS_BUILD}'
GRACE_SCAN_ROOTS='{GRACE_SCAN_ROOTS}'; GRACE_EXTRA_REPOS='{GRACE_EXTRA_REPOS}'
DETACHED_WAIT_MIN='$(jq -r '.caps.detached_wait_min // empty' "$RUN/run.json")'
EOF
. "$SCR/vars.sh"; case $STALE_DAYS in ''|*[!0-9]*|0*) echo "STALE_DAYS=3" >> "$SCR/vars.sh";; esac
```

`DISK_ONLY` runs Phase 0, Phase 5, Phase 10 and nothing else.

## Phase 1: Platform, tools, GitHub

`uname -s` ≠ `Linux` or no `/proc/self` → `ABORT_NOT_LINUX`. Then collect two lists and append them as
`TOOLS_MISSING` / `TOOLS_OPTIONAL_MISSING` (space-separated, empty when none):

- **required on `PATH`** — `git cargo rustup grpcurl jq typos gh ss curl flock nc python3 nproc setsid timeout realpath openssl`;
  plus four capability probes, recorded under the names `git>=2.38` (`git merge-tree --write-tree HEAD HEAD`),
  `git-identity` (`git var GIT_COMMITTER_IDENT`), `nightly-rustfmt` (`cargo +nightly fmt --version`) and
  `clippy` (`cargo clippy --version`);
- **optional** — `docker buf pg_isready redis-cli just diesel`.

GitHub: `gh auth status`; `git remote get-url origin` must match `github\.com[:/]juspay/hyperswitch-prism(\.git)?$`;
`gh repo view juspay/hyperswitch-prism --json viewerPermission --jq .viewerPermission`.

`ABORT_TOOLS` when a required tool is missing, `gh` is not authenticated, `origin` is not `juspay/hyperswitch-prism`
(2.4_pr.md "HARD GUARDRAIL — TARGET REPOSITORY"), or the permission is not `ADMIN`, `MAINTAIN` or `WRITE`.
`nightly-rustfmt` is required because `make validate-pre-push-fix` runs `cargo +nightly fmt --all`; `git-identity`
(`user.name` / `user.email` resolvable) because 2_connector.md `snapshot()` runs `git commit-tree` and 2.8_pr_run.md
commits; `openssl` runs the webhook signing self-test in 2.6c_test_requests.md; git ≥ 2.38 provides
`merge-tree --write-tree` for 2.8_pr_run.md (older git exits 129). `docker` (HS bootstrap can go native), `buf` (2.6c_test_requests.md shape check falls to `shape_check.method: "none"`, `PARTIAL`; S4z `buf lint`
when proto changed) and `pg_isready` / `redis-cli` / `just` / `diesel` (DB check and migrations in 2.6a_test_env.md
"3e Bootstrap") are recorded in `tools.optional_missing[]`, not required.

## Phase 2: Credentials

Resolution order is the harness's (`crates/internal/integration-tests/src/harness/credentials.rs`, `creds_file_path()`):
`CONNECTOR_AUTH_FILE_PATH` → `UCS_CREDS_PATH` → `creds.json` at the repo root. `.env.connector-tests` can set either
variable and overrides the shell (`scripts/run-tests` sources it; the Makefile exports it), so load it first.

```bash
EF=false; if [ -f .env.connector-tests ]; then EF=true; set +u; . ./.env.connector-tests; set -u; fi
if   [ -n "${CONNECTOR_AUTH_FILE_PATH:-}" ]; then C="$CONNECTOR_AUTH_FILE_PATH"; S=CONNECTOR_AUTH_FILE_PATH
elif [ -n "${UCS_CREDS_PATH:-}" ];           then C="$UCS_CREDS_PATH";           S=UCS_CREDS_PATH
else C=creds.json; S=default; fi
SHAPE=$(jq -r --arg c "$CONNECTOR_LC" '
  (.[$c] // null) as $e
  | if $e == null then "MISSING"
    elif (if ($e|type)=="array" then $e[0] else $e end
          | has("connector_account_details")) then "LEGACY"
    else "OK" end' "$C" 2>/dev/null || echo INVALID)
```

Append `CREDS_PATH` (`$C` through `realpath -m` — absolute, since consumers may run outside the repo root),
`CREDS_SOURCE` (`$S`), `CREDS_ENV_FILE` (`$EF`) and `CREDS_SHAPE` (`${SHAPE:-INVALID}`).

`creds.path` is the resolved file; 2.3b, 2.6a, 2.6c, 2.6d and 2.8 read it and never re-resolve.
Shape is `MISSING`, `LEGACY`, `OK`, or `INVALID` (unreadable / not JSON). Anything but `OK` → `ABORT_CREDS`. `LEGACY`
passes a plain `jq` lookup and still fails at run time: `connector-creds` returns `CredentialError::LegacyFormat`
(`crates/internal/connector-creds/src/lib.rs`, `if obj.contains_key("connector_account_details")`). The reason tells
the operator the fix (flat keys mirroring the connector's `*Config` message in
`crates/types-traits/grpc-api-types/proto/payment.proto`); you never edit the file.

## Phase 3: UCS tree


## Phase 4: Hyperswitch checkout (read-only)

HS is **present** when `{HS_REPO_PATH}` is non-empty, is a directory, and `git -C "$HS_REPO_PATH" rev-parse
--is-inside-work-tree` succeeds; non-empty but not that → `path_invalid` (requested but unusable — never "not
requested"). When present, read and append:

| Fact | Source |
|---|---|
| dirty | `git -C "$HS_REPO_PATH" status --porcelain --untracked-files=no` non-empty |
| `hs.origin` | `git -C "$HS_REPO_PATH" remote get-url origin` |
| `HS_PORT` | the `[server]` `port` in `$HS_REPO_PATH/config/development.toml` |
| config `base_url` | the `[grpc_client.unified_connector_service]` block of the same file |
| `HS_HEALTH_PATH` | the health scope in `$HS_REPO_PATH/crates/router/src/routes/app.rs`; ambiguous → `/health` and say so |

Nothing about HS is assumed: the matched lines, with their line numbers, are the Evidence. Then probe the running
router: `curl -s -o /dev/null -w '%{http_code}' -m 5 "http://127.0.0.1:${HS_PORT}${HS_HEALTH_PATH}"` (`200` →
running); the listener pid from `ss -Htlnp "sport = :${HS_PORT}"`; and from that pid only, the one NUL-separated
`/proc/<pid>/environ` variable whose name matches both `unified_connector_service` and `base_url=`
**case-insensitively** (HS env var names are upper-case), plus `/proc/<pid>/cmdline`
(for a config passed with `-f`).

UCS `base_url` precedence: the matched environ variable (record its **name** — it is the verified HS env prefix
2.6a_test_env.md needs) → the config file passed with `-f` on the cmdline → `config/development.toml`. Append
`HS_UCS_PORT` (the URL's port, only when running). HS push permission when present:
`gh repo view <origin slug> --json viewerPermission --jq .viewerPermission`; no write access is recorded
(`hs.push=false`), not an abort.

Append `HS_MODE`:

| present | dirty | running | `HS_MODE` |
|---|---|---|---|
| no, `{HS_REPO_PATH}` empty | – | – | `skipped`, `hs.unavailable_reason` null (2.6a_test_env.md 3a `NO_CHECKOUT`: HS surfaces E2E_SKIPPED, as in 2.5_e2e.md "Phase 0: Preconditions" 0a) |
| no, `{HS_REPO_PATH}` non-empty (`path_invalid`) | – | – | `skipped`, `hs.path` = the resolved path, `hs.unavailable_reason = HS_PATH_INVALID` — HS was requested and is unusable, so 2.6a 3a fails the HS surface closed; `NO_CHECKOUT` is reachable only from the row above |
| yes | no | any | `worktree` |
| yes | yes | yes | `reuse_only` (the only reuse-only case: no patch, no rebuild) |
| yes | yes | no | `worktree` (hs-wt is cut from `origin/main` and 2.6a bootstraps from it; the dirty tree is untouched) |

Phase 8 failing turns `worktree` into `skipped`.

## Phase 5: Disk and stale-target cleanup

**5a — helpers:**

```bash
cat > {SCRATCH}/lib.sh <<'EOF'
avail() { df -Pk "$UCS_ROOT" | awk 'NR==2{print int($4/1048576)}'; }
live_in() { local l t; for l in /proc/[0-9]*/cwd /proc/[0-9]*/exe; do
  t=$(readlink "$l" 2>/dev/null) || continue; case "${t% (deleted)}/" in "$1"/*) return 0;; esac; done; return 1; }
lock_held() { local f; while read -r f; do flock -n "$f" true || return 0; done \
  < <(find "$1" -maxdepth 3 -name .cargo-lock 2>/dev/null); return 1; }
out() { printf '%s\t%s\t%s\t%s' "$1" "$2" "$3" "${4:-0}"; }   # verdict reason top last_activity
classify() { local T=$1 top gd la br slug st= r sp tf
  top=$(git -C "$(dirname "$T")" rev-parse --show-toplevel 2>/dev/null) || { out SKIP not_git -; return; }
  case "$top" in "$UCS_ROOT"|"$HS_REPO_PATH") out PROTECTED run_root "$top"; return;; esac
  case "$T/" in "$UCS_ROOT"/grace/runs/*) out PROTECTED run_dir "$top"; return;; esac
  [ "$T" = "$(realpath -m "${CARGO_TARGET_DIR:-/nonexistent}")" ] && { out PROTECTED cargo_target_dir "$top"; return; }
  gd=$(git -C "$top" rev-parse --absolute-git-dir); la=$(stat -c %Y "$gd/HEAD" "$gd/index" 2>/dev/null | sort -n | tail -1)
  [ -O "$T" ] || { out SKIP not_owner "$top" "$la"; return; }
  [ "$(stat -c %d "$T")" = "$(stat -c %d "$UCS_ROOT")" ] || { out SKIP other_filesystem "$top" "$la"; return; }
  # fail closed: an erroring git (locked/corrupt index, unreadable objects) is not "clean" or "untracked"
  sp=$(git --no-optional-locks -C "$top" status --porcelain 2>/dev/null) || { out SKIP status_error "$top" "$la"; return; }
  [ -z "$sp" ] || { out SKIP dirty "$top" "$la"; return; }
  tf=$(git -C "$(dirname "$T")" ls-files -- "$(basename "$T")" 2>/dev/null) || { out SKIP ls_files_error "$top" "$la"; return; }
  [ -z "$tf" ] || { out SKIP tracked_target "$top" "$la"; return; }
  live_in "$top" && { out SKIP live_process "$top" "$la"; return; }
  lock_held "$T" && { out SKIP cargo_lock_held "$top" "$la"; return; }
  br=$(git -C "$top" symbolic-ref --short -q HEAD)
  slug=$(git -C "$top" remote get-url origin 2>/dev/null | sed -nE 's#^.*github\.com[:/]([^/]+/[^/]+)$#\1#p' | sed 's#\.git$##')
  # only this checkout's PRs: head owner == origin owner; MERGED/CLOSED also need HEAD contained in the PR head
  case "$br" in ""|main|master) ;; *) [ -n "$slug" ] && st=$(timeout 60 gh pr list --repo "$slug" --head "$br" --state all \
    --json state,headRefOid,headRepositoryOwner 2>/dev/null | jq -r --arg o "${slug%%/*}" \
    '.[]|select((.headRepositoryOwner.login|ascii_downcase)==($o|ascii_downcase))|"\(.state) \(.headRefOid)"' |
    while read -r s oid; do [ "$s" = OPEN ] || git -C "$top" merge-base --is-ancestor HEAD "$oid" 2>/dev/null && echo "$s"
    done | sort -u | paste -sd, -);; esac
  case ",$st," in *,OPEN,*) ;; *,MERGED,*|*,CLOSED,*) out ELIGIBLE_PR "pr_$st" "$top" "$la"; return;; esac
  r=$(find "$T" "$gd/HEAD" "$gd/index" -mtime "-${STALE_DAYS:-3}" -print -quit 2>/dev/null) \
    || { out KEEP find_error "$top" "$la"; return; }                    # fail closed: an erroring find is not "idle"
  [ -z "$r" ] && { out ELIGIBLE_IDLE "idle_gt_${STALE_DAYS:-3}d" "$top" "$la"; return; }
  out KEEP recent_activity "$top" "$la"; }
# long/waitx: verbatim from 2.3b_codegen_unit.md Setup
long() { local p=$1; shift; rm -f "$p.exit" "$p.pid"
  nohup setsid bash -c 'p=$1; shift; echo $$ >"$p.pid"; s=$(date +%s); "$@" >"$p.log" 2>&1; e=$?
    echo "$e $(( $(date +%s) - s ))" >"$p.exit.tmp" && mv "$p.exit.tmp" "$p.exit"' _ "$p" "$@" </dev/null >/dev/null 2>&1 & }
waitx() { timeout 540 bash -c 'until [ -e "$0" ]; do sleep 15; done' "$1.exit" && { cat "$1.exit"; return; }
  [ $(( $(date +%s) - $(stat -c %Y "$1.pid" 2>/dev/null || echo 0) )) -ge $(( ${DETACHED_WAIT_MIN:?} * 60 )) ] || return 124
  local j; j=$(cat "$1.pid"); case "$(readlink "/proc/$j/exe" 2>/dev/null)" in */bash)
    tr '\0' ' ' <"/proc/$j/cmdline" | grep -qF -- "$1" && kill -TERM -- "-$j";; esac; echo "TIMEOUT:$1"; return 125; }
EOF
```

Append `THRESH` — `{MIN_FREE_GB_RUNTIME}` or 20 in `DISK_ONLY`, else `{MIN_FREE_GB}` or (80 when `HS_MODE=worktree`,
which adds an HS build, else 50) — and `BEFORE=$(avail)`.

`BEFORE` ≥ `THRESH` → skip 5b–5c (`disk.scanned=false`, `after_gb=before_gb`). 5b and 5c run detached (the
`find`, `gh`, `du` and `rm` walks can pass the Bash tool's 10-minute limit): each block only launches with `long`; the
join call is `. {SCRATCH}/vars.sh; . {SCRATCH}/lib.sh; waitx <prefix>`, under the Phase 9 detached-job contract
(`TIMEOUT:<prefix>` → `ABORT_DISK`, REASON `TIMEOUT:<prefix>`).

**5b — discover and classify:**

```bash
cat > {SCRATCH}/scan.sh <<'EOF'
. {SCRATCH}/vars.sh; . {SCRATCH}/lib.sh
{ for r in "$UCS_ROOT" ${HS_REPO_PATH:+"$HS_REPO_PATH"} $GRACE_EXTRA_REPOS; do
    git -C "$r" worktree list --porcelain 2>/dev/null | sed -n 's/^worktree //p' |
      while read -r w; do [ -d "$w/target" ] && echo "$w/target"; done; done
  # Opt-in only: with GRACE_SCAN_ROOTS empty, nothing outside the repos above is ever a candidate.
  if [ -n "$GRACE_SCAN_ROOTS" ]; then
    find $GRACE_SCAN_ROOTS -maxdepth 3 -type d -name target -prune -exec test -f '{}/../Cargo.toml' ';' -print 2>/dev/null
  fi
} | xargs -r -d '\n' realpath -e 2>/dev/null | sort -u | while read -r T; do
  g=$(timeout 120 du -sk "$T" 2>/dev/null | awk '{print int($1/1048576)}')
  printf '%s\t%s\t%s\n' "$T" "$(classify "$T")" "${g:-unknown}"
done > {SCRATCH}/candidates.tsv.tmp && mv {SCRATCH}/candidates.tsv.tmp {SCRATCH}/candidates.tsv
EOF
long {SCRATCH}/scan bash {SCRATCH}/scan.sh                                  # then join: waitx {SCRATCH}/scan
```

`candidates.tsv` columns: `path  verdict  reason  top  last_activity  size_gb|unknown`.

**5c — delete**: merged/closed PR first, then idle; oldest activity first within each; stop at `THRESH`:

```bash
cat > {SCRATCH}/clean.sh <<'EOF'
. {SCRATCH}/vars.sh; . {SCRATCH}/lib.sh; : > {SCRATCH}/deleted.tsv
awk -F'\t' '$2 ~ /^ELIGIBLE_/' {SCRATCH}/candidates.tsv | sort -t $'\t' -k2,2r -k5,5n |
while IFS=$'\t' read -r T v r top la gb; do
  [ "$(avail)" -ge "$THRESH" ] && break
  case "$(classify "$T")" in ELIGIBLE_*) ;; *) continue;; esac          # re-check immediately before rm
  rm -rf -- "$T" && printf '%s\t%s\t%s\n' "$T" "$r" "$gb" >> {SCRATCH}/deleted.tsv
done
echo "AFTER=$(avail)" >> {SCRATCH}/vars.sh
EOF
long {SCRATCH}/clean bash {SCRATCH}/clean.sh                                # then join: waitx {SCRATCH}/clean
```

`AFTER` < `THRESH` → `ABORT_DISK`; the reason names free vs threshold and the three largest candidates (path, size,
verdict, reason); `candidates[]` holds the full list. One decisions row per deletion.

## Phase 6: grpc-servers and ports

Every `grpc-server` whose `/proc/<pid>/exe` is under `$UCS_ROOT/target/` is listed, never killed: an orphan may be a
developer's `make start-grpc` server (Makefile `GRPC_PID_FILE`), which no run owns. Reason `owned_by_active_run` when an
active run lists its pid (a run dir whose `run.json` lacks `ended_at`, or is missing, is active; its `*.pid` files up to
depth 2 are read), else `not_owned`. Scan `/proc/[0-9]*/exe` by `readlink` (strip a ` (deleted)` suffix) and write
`{SCRATCH}/servers.tsv`, one `pid  exe  reason` row per match. The port picker below skips whatever they hold.

Ports: gRPC = `HS_UCS_PORT` if HS is running and that port is free, else the first free 8000+k; metrics = the first
free 9180+k (k < 100). Never 8080 (`config/development.toml` `[metrics] port = 8080`, and HS commonly binds it), never
`HS_PORT`, never a port in another active run's `preflight.json` `.ports.grpc` / `.ports.metrics` (every
`grace/runs/*/` but this one whose `run.json` lacks `ended_at`), never one `ss -Htln "sport = :<p>"` shows as
listening. Append `GRPC_PORT` and
`METRICS_PORT`; `ports.grpc_source` is `hs_base_url` when the gRPC port came from `HS_UCS_PORT`, else `scan`. No free
port in a window of 100 → `FAILED`.

## Phase 7: Run branch

`BRANCH` is `feat/grace-${CONNECTOR_LC}-${RUN6}`. An existing `refs/heads/$BRANCH` is reused (`BRANCH_REUSED=true`)
only when `git rev-list --count "origin/main..$BRANCH"` is `0`. Only when the branch does **not** exist, create it with
`git switch --no-track -c "$BRANCH" origin/main` (`BRANCH_REUSED=false`); an existing branch carrying commits not on
`origin/main` is `ABORT_DIRTY` and is **never** re-created or reset (no `switch -C`, no `-B`). On success append `BRANCH`,
`BRANCH_REUSED`, `BASE_SHA` (`git rev-parse HEAD`) and `STASH_COUNT` (`git stash list | wc -l`); on either failure
`ABORT_DIRTY`.

`stash_count` (taken after the switch) is the stage-end guard baseline 2_connector.md and 2.8_pr_run.md read.
`ABORT_DIRTY` here means the existing branch has commits not on `origin/main`, or `switch` refused (an untracked file
would be overwritten); quote git's message. `--no-track` keeps `origin/main` from becoming the upstream.

## Phase 8: HS worktree

Only when `HS_MODE=worktree`. The path must be absolute: `git -C` resolves a relative `{RUN_DIR}` against the HS checkout.

`HS_WT` = `$RUN_ABS/hs-wt`, `HS_BRANCH` = `feat/${CONNECTOR_LC}-ucs-${RUN6}`. An existing `$HS_WT/.git` is reused iff
its `HEAD` is already `$HS_BRANCH`; otherwise `git -C "$HS_REPO_PATH" fetch origin main`, then `worktree add "$HS_WT"
"$HS_BRANCH"` when that branch exists, else `worktree add --no-track -b "$HS_BRANCH" "$HS_WT" origin/main`. Append the
pair on success, else `HS_WORKTREE_FAILED` and `HS_MODE=skipped`. Append `HS_ROUTER_BIN=1` when the worktree's
`crates/router/Cargo.toml` has a `[[bin]]` with `name = "router"`.

`HS_WORKTREE_FAILED` is not an abort: `HS_MODE=skipped` whether or not HS runs (a present checkout makes 2.6a_test_env.md
3a report `HS_WORKTREE_FAILED`: HS surface `FAILED`, never E2E_SKIPPED); quote git's message in the decisions row. No
`router` bin in `crates/router/Cargo.toml` → no HS warm build (recorded).

## Phase 9: Background warm builds

Start after Phase 7 so they compile `BASE_SHA`. One serial UCS chain (cargo serialises on the target-dir lock anyway),
ordered by first consumer: `ucs_build` first (the exact command of 2.6a_test_env.md "Phase 1: UCS build (one per
round)": every BASELINE binary — `grpc-server`, `test_ucs`, `check_connector_specs`, `mask_report_creds`,
`check_report_creds` — and its `ucs_build.exit`; `env -u CARGO_TARGET_DIR` mirrors 2.6a's `unset`, so both land in
`target/debug/`) → `clippy` (as in `scripts/validation/pre-push.sh`) → `clippy_gate`
(2.3b_codegen_unit.md gate) → `field_probe` (Makefile `field-probe` target, run by `make docs` inside
`make validate-pre-push-fix` at S4z). The HS router builds in `hs-wt`
with `CARGO_TARGET_DIR=$HS_REPO_PATH/target`, in parallel when `PARALLEL_HS_BUILD=1`, else last in the UCS chain.

HS builds at all only when `HS_MODE=worktree` and `HS_ROUTER_BIN=1` — then `HPAR=1` if `PARALLEL_HS_BUILD=1` else
`HSER=1`, both `0` otherwise. `PLATFORM` is `aarch64-unknown-linux-gnu` on `uname -m` = `aarch64`, else
`x86_64-unknown-linux-gnu` (the Makefile `PLATFORM`). `W` = `$RUN_ABS/warm`.

```bash
cat > "$W/warm.sh" <<'EOF'
#!/usr/bin/env bash
# warm.sh <warm_dir> ucs <platform> <hs_serial 0|1> <hs_wt> <hs_target> | warm.sh <warm_dir> hs <hs_wt> <hs_target>
set -u; W=$1; shift
step() { local n=$1; shift; "$@" >"$W/$n.log" 2>&1; echo $? >"$W/$n.exit.tmp"; mv "$W/$n.exit.tmp" "$W/$n.exit"; }
hs() { (cd "$1" && step hs_router env CARGO_TARGET_DIR="$2" cargo build --bin router); }
if [ "$1" = ucs ]; then
  step ucs_build   env -u CARGO_TARGET_DIR cargo build -p grpc-server -p integration-tests --bin grpc-server --bin test_ucs \
                     --bin check_connector_specs --bin mask_report_creds --bin check_report_creds
  step clippy      cargo clippy --all-features --all-targets -- -D warnings
  step clippy_gate cargo clippy -p connector-integration --all-features -- -D warnings
  step field_probe cargo build -p field-probe --target "$2" --profile release-fast
  [ "$3" = 1 ] && hs "$4" "$5"
else hs "$2" "$3"; fi
EOF
```

Launch it `nohup setsid`, pid to `warm/<ucs|hs>.pid` (`.tmp` + `mv`), skipping a launch whose recorded pid is still
alive (`kill -0`) — that is the crash-re-spawn case: `bash "$W/warm.sh" "$W" ucs "$PLATFORM" "$HSER" "${HS_WT:-}"
"$HS_REPO_PATH/target"`, and when `HPAR=1` a second `bash "$W/warm.sh" "$W" hs "$HS_WT" "$HS_REPO_PATH/target"`.

Contract: `warm/<step>.exit` (exit code, atomic) exists ⇔ the step finished; `warm/<step>.log` is its output. Warm
builds are a cache, not a gate: a non-zero `clippy` exit at `BASE_SHA` is pre-existing — record it, never fix it.
BASELINE executes the `target/debug/` binaries directly (no `cargo run`, no `make`), so after `ucs_build.exit` it
never waits on the cargo lock the later steps hold.
`hs_router` is the 2.6a_test_env.md "3e Bootstrap" build with `<bin>`=`router`; keep the two identical or the cache misses.

**Detached-job contract** (`long`/`waitx`; code verbatim from the `2.3b_codegen_unit.md` Setup block; every stage cites
this paragraph):
- `long <prefix> <cmd…>` starts a `setsid` job: `<prefix>.pid` = its process-group leader (written at launch),
  `<prefix>.log` = output, `<prefix>.exit` = `<exit> <duration_s>` (atomic; exists ⇔ finished).
- Launch and join are separate Bash calls on the same `<prefix>` string. A join call runs one `waitx <prefix>` (≤540 s).
  It, and every call that runs a health/readiness wait loop, passes the Bash tool parameter `timeout: 600000` (the
  120000 ms default kills it first).
- `waitx` exit 124 → the join call again; never re-launch while `<prefix>.exit` is absent. Once the launch is older
  than `DETACHED_WAIT_MIN` (each Setup binds `run.json .caps.detached_wait_min`, `2_connector.md` "## Caps"; no
  `<prefix>.pid` counts as older), `waitx` kills the job's process group (2_connector.md R12 carve-out), prints `TIMEOUT:<prefix>` and exits 125: the step
  failed, REASON `TIMEOUT:<prefix>`.

## Phase 10: Write outputs

Build the JSON with `jq -n` from `vars.sh` and `{SCRATCH}/*.tsv|*.txt` (e.g. `jq -R -s 'split("\n")|map(select(length>0)|split("\t"))'`).
Write `<path>.tmp` then `mv`, decisions first, primary output last: `FULL` → `{RUN_DIR}/preflight.decisions.md`,
`{RUN_DIR}/preflight.json`; `DISK_ONLY` → `{RUN_DIR}/disk/{DISK_TAG}.decisions.md`, `{RUN_DIR}/disk/{DISK_TAG}.json`.

Decisions file: a table `| Decision | Options considered | Chosen | Why | Evidence / source |` with a row for the
threshold, scan run or skipped, every deletion, the grpc-servers found, ports, creds source, HS port / health path /
base_url source and env variable name, `HS_MODE`, branch reuse, workflow dir, warm order and parallelism, and the HS
router bin check. On abort, the row that caused it.
