# proffi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build proffi, a Rust workspace at `~/src/proffi` providing a runtime crate, attribute macros, build helper, and codegen CLI that let users declare protobuf services as FFI surfaces and generate Python/Kotlin/JavaScript SDKs over a UniFFI cdylib.

**Architecture:** Five-crate Cargo workspace. `proffi-runtime` owns the byte envelope (`FfiResult`, `Error`) and the generic `run::<Req, Res>` runner. `proffi-macros` provides `#[proffi::rpc]` (UniFFI export wrapper + per-rpc manifest JSON) and `proffi::setup!()`. `proffi-build` is called from user `build.rs`; runs `prost-build`, captures `FileDescriptorSet`, writes `descriptor.bin`, clears the intermediate dir. `proffi` is a thin facade re-exporting all three plus a pinned `uniffi`. `proffi-cli` (`proffi`) is a binary with `generate|check|list` that consumes the descriptor + per-rpc JSONs to render Python/Kotlin/JavaScript wrappers using `uniffi_bindgen` as a library and `protoc` for proto stubs.

**Tech Stack:** Rust 2021, `prost 0.14`, `uniffi 0.29`, `syn 2`, `quote`, `serde_json`, `prost-build`, `prost-types`, `clap 4`, `minijinja 2`, `uniffi_bindgen 0.29`. JS wrapper uses `koffi`. External CLI dep: `protoc` on PATH.

**Spec refinement note (read before starting):** The design spec describes `proffi_build::finalize()` (called from `build.rs`) doing per-handler ↔ proto validation. Cargo's build order makes that impossible: `build.rs` runs *before* proc-macros expand, so `build.rs` can't see what the macros emitted. This plan therefore splits the validation:
- **Per-handler validation** (rpc exists, types align) → runs at macro-expansion time. The macro reads `descriptor.bin` (written earlier by `build.rs`'s `compile()`) and emits `compile_error!()` on mismatch. **Still compile-time, still hard-fails the build.**
- **"Every rpc covered" validation** → runs in `proffi check` (and implicitly in `proffi generate`). Easy to wire into CI as a follow-up step. The configurable `allow_partial` flag lives on the CLI flag, not on a build helper config.

This is a small but real adjustment to the spec; everything else holds.

package proffi;

import "google/protobuf/any.proto";

// Reserved system error codes, used by the FFI runtime itself.
//   DECODE_FAILED   – the input bytes did not parse as the expected request proto.
//   HANDLER_PANIC   – the user handler panicked; the runner caught it.
//   INTERNAL        – any other failure attributable to the FFI runtime.
// Domain errors are NOT proffi's concern: model them inside your own response proto.
message Error {
  string code = 1;
  string message = 2;
  google.protobuf.Any details = 3;
}

message FfiResult {
  oneof payload {
    bytes ok  = 1;
    Error err = 2;
  }
}
```

use std::panic::AssertUnwindSafe;
use prost::Message;

use crate::{Error, FfiResult, Payload, proto};

pub fn run<Req, Res, F>(input: Vec<u8>, handler: F) -> Vec<u8>
where
    Req: prost::Message + Default,
    Res: prost::Message,
    F: FnOnce(Req) -> Result<Res, Error>,
{
    let outcome = std::panic::catch_unwind(AssertUnwindSafe(|| {
        let req = Req::decode(&*input).map_err(|e| Error::decode(e))?;
        handler(req)
    }));

    let payload = match outcome {
        Ok(Ok(res))  => Payload::Ok(res.encode_to_vec()),
        Ok(Err(e))   => Payload::Err(proto::Error::from(e)),
        Err(panic)   => Payload::Err(proto::Error::from(Error::from_panic(panic))),
    };

    FfiResult { payload: Some(payload) }.encode_to_vec()
}
```

use syn::{parse2, FnArg, ItemFn, LitStr, Meta, Pat, ReturnType, Token, Type};
use syn::punctuated::Punctuated;

pub struct Args {
    pub service: String,
    pub method:  String,
    pub request_override:  Option<String>,
    pub response_override: Option<String>,
}

impl Args {
    fn parse(attr: TokenStream) -> syn::Result<Self> {
        let nested: Punctuated<Meta, Token![,]> =
            Punctuated::parse_terminated.parse2(attr)?;

        let mut service = None;
        let mut method  = None;
        let mut request_override  = None;
        let mut response_override = None;

        for meta in nested {
            let nv = match meta {
                Meta::NameValue(nv) => nv,
                other => return Err(syn::Error::new_spanned(
                    other, "expected `name = \"value\"` argument")),
            };
            let key = nv.path.get_ident()
                .map(|i| i.to_string())
                .unwrap_or_default();
            let value = match &nv.value {
                syn::Expr::Lit(syn::ExprLit { lit: syn::Lit::Str(s), .. }) => s.value(),
                _ => return Err(syn::Error::new_spanned(
                    &nv.value, "expected string literal")),
            };
            match key.as_str() {
                "service"  => service  = Some(value),
                "method"   => method   = Some(value),
                "request"  => request_override  = Some(value),
                "response" => response_override = Some(value),
                other => return Err(syn::Error::new_spanned(
                    nv.path, format!("unknown argument `{other}`"))),
            }
        }

        Ok(Args {
            service:  service.ok_or_else(|| syn::Error::new(
                proc_macro2::Span::call_site(),
                "#[proffi::rpc] requires `service = \"...\"`"))?,
            method:   method.ok_or_else(|| syn::Error::new(
                proc_macro2::Span::call_site(),
                "#[proffi::rpc] requires `method = \"...\"`"))?,
            request_override,
            response_override,
        })
    }
}

pub struct HandlerSig {
    pub fn_name:   syn::Ident,
    pub req_type:  Type,
    pub res_type:  Type,
}

impl HandlerSig {
    fn parse(item: &ItemFn) -> syn::Result<Self> {
        if item.sig.asyncness.is_some() {
            return Err(syn::Error::new_spanned(
                &item.sig.fn_token,
                "async handlers are not supported in proffi 0.1 (sync only)"));
        }

        if item.sig.inputs.len() != 1 {
            return Err(syn::Error::new_spanned(
                &item.sig.inputs,
                "proffi handlers must take exactly one argument: the request proto"));
        }
        let req_type = match item.sig.inputs.first().unwrap() {
            FnArg::Typed(p) => match &*p.pat {
                Pat::Ident(_) => (*p.ty).clone(),
                _ => return Err(syn::Error::new_spanned(p, "expected named argument")),
            },
            FnArg::Receiver(r) => return Err(syn::Error::new_spanned(
                r, "proffi handlers cannot have a self receiver")),
        };

        let res_type = match &item.sig.output {
            ReturnType::Type(_, ty) => extract_result_ok_type(ty)?,
            ReturnType::Default => return Err(syn::Error::new_spanned(
                &item.sig,
                "proffi handlers must return Result<Response, proffi::Error>")),
        };

        Ok(HandlerSig {
            fn_name: item.sig.ident.clone(),
            req_type,
            res_type,
        })
    }
}

fn extract_result_ok_type(ty: &Type) -> syn::Result<Type> {
    if let Type::Path(tp) = ty {
        if let Some(last) = tp.path.segments.last() {
            if last.ident == "Result" {
                if let syn::PathArguments::AngleBracketed(ab) = &last.arguments {
                    if let Some(syn::GenericArgument::Type(ok_ty)) = ab.args.first() {
                        return Ok(ok_ty.clone());
                    }
                }
            }
        }
    }
    Err(syn::Error::new_spanned(
        ty, "proffi handlers must return Result<Response, proffi::Error>"))
}

    let sig = HandlerSig::parse(&item_fn)?;

    let _ = (args, sig);

            }
        }

    }

    fq.trim_start_matches('.').rsplit('.').next().unwrap_or(fq)
}

pub fn last_segment_of_rust_path(p: &str) -> &str {

}

use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Entry {
    pub service:        String,
    pub method:         String,
    pub rust_fn:        String,
    pub req_type_rust:  String,
    pub res_type_rust:  String,
    pub req_type_proto: Option<String>,
    pub res_type_proto: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Manifest {
    pub crate_name: String,
    pub entries:    Vec<Entry>,
}

impl Manifest {
    pub fn aggregate(crate_name: &str, intermediate_dir: &Path) -> Result<Self> {
        let mut entries = Vec::new();
        for ent in walkdir::WalkDir::new(intermediate_dir).into_iter().filter_map(|e| e.ok()) {
            if ent.file_type().is_file()
                && ent.path().extension().and_then(|s| s.to_str()) == Some("json") {
                let raw = std::fs::read_to_string(ent.path())
                    .with_context(|| format!("reading {}", ent.path().display()))?;
                entries.push(serde_json::from_str(&raw)
                    .with_context(|| format!("parsing {}", ent.path().display()))?);
            }
        }
        // Stable sort for deterministic output.
        entries.sort_by(|a, b| (a.service.as_str(), a.method.as_str())
            .cmp(&(b.service.as_str(), b.method.as_str())));
        Ok(Manifest { crate_name: crate_name.to_string(), entries })
    }

    pub fn write(&self, path: &Path) -> Result<()> {
        if let Some(parent) = path.parent() { std::fs::create_dir_all(parent)?; }
        std::fs::write(path, serde_json::to_string_pretty(self)?)?;
        Ok(())
    }
}

pub fn target_proffi_root(manifest_dir_override: Option<PathBuf>, crate_name: &str) -> PathBuf {
    if let Some(p) = manifest_dir_override { return p; }
    let target = std::env::var_os("CARGO_TARGET_DIR")
        .map(PathBuf::from)
        .unwrap_or_else(|| PathBuf::from("target"));
    target.join("proffi").join(crate_name)
}

use anyhow::Result;
use clap::Parser;
use cli::{Cli, Cmd, Lang};

fn main() -> Result<()> {
    let args = Cli::parse();
    let crate_name = args.crate_name.clone()
        .or_else(|| std::env::var("CARGO_PKG_NAME").ok())
        .or_else(detect_crate_name_from_cwd)
        .ok_or_else(|| anyhow::anyhow!("could not determine --crate-name"))?;
    let root = manifest::target_proffi_root(args.manifest_dir.clone(), &crate_name);

    match args.command {
        Cmd::List => list(&root, &crate_name),
        Cmd::Check { allow_partial } => check(&root, &crate_name, allow_partial),
        Cmd::Generate { .. } => {
            anyhow::bail!("generate: implemented in later phases");
        }
    }
}

fn detect_crate_name_from_cwd() -> Option<String> {
    let cargo = std::path::Path::new("Cargo.toml");
    if !cargo.exists() { return None; }
    let s = std::fs::read_to_string(cargo).ok()?;
    for line in s.lines() {
        let t = line.trim();
        if let Some(rest) = t.strip_prefix("name") {
            let rest = rest.trim().trim_start_matches('=').trim();
            return Some(rest.trim_matches('"').to_string());
        }
    }
    None
}

fn list(root: &std::path::Path, crate_name: &str) -> Result<()> {
    let m = manifest::Manifest::aggregate(crate_name, &root.join("intermediate"))?;
    println!("crate: {}\nrpcs:", m.crate_name);
    for e in &m.entries {
        println!("  {}.{}\t→ {}\t({} → {})",
            e.service, e.method, e.rust_fn, e.req_type_rust, e.res_type_rust);
    }
    Ok(())
}

fn check(root: &std::path::Path, crate_name: &str, allow_partial: bool) -> Result<()> {
    let m = manifest::Manifest::aggregate(crate_name, &root.join("intermediate"))?;
    let set = descriptor::load(&root.join("descriptor.bin"))?;

    use std::collections::BTreeSet;
    let proto_set: BTreeSet<(String, String)> = descriptor::iter_rpcs(&set).collect();
    let handler_set: BTreeSet<(String, String)> = m.entries.iter()
        .map(|e| (e.service.clone(), e.method.clone()))
        .collect();

    let extra: Vec<_> = handler_set.difference(&proto_set).collect();
    let missing: Vec<_> = proto_set.difference(&handler_set).collect();

    if !extra.is_empty() {
        for (s, mth) in &extra {
            eprintln!("error: handler points to non-existent rpc {s}.{mth}");
        }
        anyhow::bail!("{} handler(s) reference unknown rpcs", extra.len());
    }
    if !missing.is_empty() {
        for (s, mth) in &missing {
            eprintln!("{}: rpc {s}.{mth} has no handler",
                if allow_partial { "warning" } else { "error" });
        }
        if !allow_partial {
            anyhow::bail!("{} rpc(s) without handlers (use --allow-partial to downgrade to warning)",
                missing.len());
        }
    }

    println!("ok: {} handlers cover {} rpcs", handler_set.len(), proto_set.len());
    Ok(())
}

fn run_protoc(protos: &[std::path::PathBuf], out: &Path, lang: &str) -> Result<()> {

fn workspace_proto(name: &str) -> std::path::PathBuf {
    // Best-effort lookup: the `proto/` dir at the proffi workspace root.
    // Users can override by env var PROFFI_PROTO_DIR.
    if let Ok(d) = std::env::var("PROFFI_PROTO_DIR") {
        return std::path::PathBuf::from(d).join(name);
    }
    std::path::PathBuf::from(env!("CARGO_MANIFEST_DIR"))
        .ancestors()
        .find(|p| p.join("proto").join(name).exists())
        .map(|p| p.join("proto").join(name))
        .unwrap_or_else(|| std::path::PathBuf::from("proto").join(name))
}

struct ServiceCtx {
    py_class: String,
    py_attr:  String,
    rpcs:     Vec<RpcCtx>,
}

#[derive(serde::Serialize)]
struct RpcCtx {
    py_method: String,
    rust_fn:   String,
    res_pb:    String,
}

fn group_by_service(m: &Manifest, set: &FileDescriptorSet) -> Vec<ServiceCtx> {
    use std::collections::BTreeMap;
    let mut by_svc: BTreeMap<String, Vec<&crate::manifest::Entry>> = BTreeMap::new();
    for e in &m.entries {
        by_svc.entry(e.service.clone()).or_default().push(e);
    }
    by_svc.into_iter().map(|(svc, entries)| {
        let last_seg = svc.rsplit('.').next().unwrap_or(&svc).to_string();
        let py_attr = pascal_to_snake(&last_seg);
        ServiceCtx {
            py_class: last_seg.clone(),
            py_attr,
            rpcs: entries.into_iter().map(|e| RpcCtx {
                py_method: pascal_to_snake(&e.method),
                rust_fn:   e.rust_fn.clone(),
                res_pb:    res_pb_path(e, set),
            }).collect(),
        }
    }).collect()
}

fn pascal_to_snake(s: &str) -> String {
    let mut out = String::new();
    for (i, c) in s.chars().enumerate() {
        if c.is_uppercase() && i > 0 { out.push('_'); }
        out.push(c.to_ascii_lowercase());
    }
    out
}

fn res_pb_path(e: &crate::manifest::Entry, set: &FileDescriptorSet) -> String {
    // Best-effort: locate the proto file containing the rpc, return "<file_stem>_pb2.<MessageName>"
    let last = e.res_type_rust.rsplit("::").next().unwrap_or(&e.res_type_rust).to_string();
    for f in &set.file {
        if let Some(svc) = f.service.iter().find(|s| {
            s.name.as_deref().map(|n| {
                let pkg = f.package.as_deref().unwrap_or("");
                if pkg.is_empty() { n == e.service.as_str() }
                else { format!("{pkg}.{n}") == e.service }
            }).unwrap_or(false)
        }) {
            let _ = svc;
            let stem = f.name.as_deref().and_then(|n|
                std::path::Path::new(n).file_stem().and_then(|s| s.to_str()))
                .unwrap_or("proto");
            return format!("{stem}_pb2.{last}");
        }
    }
    format!("proto_pb2.{last}")
}

fn collect_proto_modules(set: &FileDescriptorSet) -> Vec<String> {
    set.file.iter().filter_map(|f| f.name.as_deref()
        .and_then(|n| std::path::Path::new(n).file_stem().and_then(|s| s.to_str()))
        .map(|s| s.to_string()))
        .collect()
}

// AUTO-GENERATED by proffi {{ proffi_version }}
// DO NOT EDIT — regenerate with `proffi generate --lang javascript`
const koffi = require("koffi");
const path = require("path");

const lib = koffi.load(process.env.PROFFI_LIB_PATH || path.join(__dirname, "lib{{ crate_name }}{{ lib_ext }}"));

const RustBuffer = koffi.struct("RustBuffer", {
    data:     "void *",
    len:      "uint64",
    capacity: "uint64",
});

// UniFFI exposes a per-crate buffer free fn. Adjust if pinned uniffi changes the symbol.
const rust_buffer_free = lib.func("ffi_{{ crate_name }}_rust_buffer_free", "void", [RustBuffer, "void *"]);
const RustCallStatus = koffi.struct("RustCallStatus", {
    code:        "int8",
    error_buf:   RustBuffer,
});

function callBytes(fn, inputBytes) {
    const buf = Buffer.from(inputBytes);
    const inRb = { data: koffi.address(buf), len: BigInt(buf.length), capacity: BigInt(buf.length) };
    const status = { code: 0, error_buf: { data: null, len: 0n, capacity: 0n } };
    const outRb = fn(inRb, status);
    if (status.code !== 0) {
        throw new Error("FFI call failed (code " + status.code + ")");
    }
    const outBytes = Buffer.from(koffi.decode(outRb.data, "uint8 [" + Number(outRb.len) + "]"));
    rust_buffer_free(outRb, null);
    return outBytes;
}

module.exports = {
    callBytes,
    raw: {
{% for rpc in all_rpcs %}
        {{ rpc.rust_fn }}: lib.func("{{ rpc.rust_fn }}", RustBuffer, [RustBuffer, RustCallStatus]),
{% endfor %}
    },
};

class ProffiError extends Error {
    constructor(code, message) { super(`${code}: ${message}`); this.code = code; }
}

function decodeEnvelope(outBytes, ResCls) {
    const env = FfiResult.deserializeBinary(outBytes);
    if (env.hasErr()) {
        const e = env.getErr();
        throw new ProffiError(e.getCode(), e.getMessage());
    }
    return ResCls.deserializeBinary(env.getOk_asU8());
}

```rust
use anyhow::{Context, Result};
use minijinja::{context, Environment};
use std::path::Path;
use std::process::Command;

use super::{python, GenerateInput};
use crate::manifest::Manifest;
use prost_types::FileDescriptorSet;

pub fn generate(input: GenerateInput<'_>) -> Result<()> {
    std::fs::create_dir_all(&input.out_dir)?;
    let proto_dir = input.out_dir.join("proto");
    std::fs::create_dir_all(&proto_dir)?;

    // protoc-gen-js is bundled with the protobuf-javascript repo or installed via
    // npm install -g protoc-gen-js. We invoke it via protoc --js_out.
    let mut all = input.proto_files.clone();
    all.push(python::workspace_proto("proffi.proto"));
    run_protoc_js(&all, &proto_dir)?;

    // Stage the cdylib next to the generated module.
    if input.lib_path.exists() {
        let target = input.out_dir.join(input.lib_path.file_name().unwrap());
        let _ = std::fs::copy(&input.lib_path, &target);
    }

    let lib_ext = match std::env::consts::OS {
        "macos" => ".dylib",
        "linux" => ".so",
        "windows" => ".dll",
        _ => "",
    };

    let mut env = Environment::new();
    env.add_template("ffi.js",       include_str!("../../templates/javascript/ffi.js.jinja"))?;
    env.add_template("client.js",    include_str!("../../templates/javascript/client.js.jinja"))?;
    env.add_template("package.json", include_str!("../../templates/javascript/package.json.jinja"))?;

    let services = group_by_service(input.manifest);
    let all_rpcs: Vec<_> = services.iter().flat_map(|s| s.rpcs.iter().cloned()).collect();
    let proto_modules = super::python::collect_proto_modules(input.descriptor);
    let _ = proto_modules;
    let proto_modules = collect_proto_modules(input.descriptor);

    let render_ctx = context! {
        proffi_version => env!("CARGO_PKG_VERSION"),
        crate_name     => input.crate_name,
        lib_ext        => lib_ext,
        services       => services,
        all_rpcs       => all_rpcs,
        proto_modules  => proto_modules,
    };

    std::fs::write(input.out_dir.join("ffi.js"),
        env.get_template("ffi.js")?.render(&render_ctx)?)?;
    std::fs::write(input.out_dir.join("client.js"),
        env.get_template("client.js")?.render(&render_ctx)?)?;
    std::fs::write(input.out_dir.join("package.json"),
        env.get_template("package.json")?.render(&render_ctx)?)?;

    Ok(())
}

fn run_protoc_js(protos: &[std::path::PathBuf], out: &Path) -> Result<()> {
    let mut cmd = Command::new("protoc");
    cmd.arg(format!("--js_out=import_style=commonjs,binary:{}", out.display()));
    for p in protos {
        cmd.arg(p);
        if let Some(parent) = p.parent() { cmd.arg(format!("-I={}", parent.display())); }
    }
    let st = cmd.status().context("protoc js")?;
    if !st.success() { anyhow::bail!("protoc {st}"); }
    Ok(())
}

fn collect_proto_modules(set: &FileDescriptorSet) -> Vec<String> {
    set.file.iter().filter_map(|f| f.name.as_deref()
        .and_then(|n| std::path::Path::new(n).file_stem().and_then(|s| s.to_str()))
        .map(|s| s.to_string()))
        .filter(|n| n != "proffi")
        .collect()
}

#[derive(serde::Serialize, Clone)]
struct ServiceCtx {
    js_class: String,
    js_attr:  String,
    rpcs:     Vec<RpcCtx>,
}

#[derive(serde::Serialize, Clone)]
struct RpcCtx {
    js_method: String,
    rust_fn:   String,
    res_js:    String,
}

fn group_by_service(m: &Manifest) -> Vec<ServiceCtx> {
    use std::collections::BTreeMap;
    let mut by: BTreeMap<String, Vec<&crate::manifest::Entry>> = BTreeMap::new();
    for e in &m.entries { by.entry(e.service.clone()).or_default().push(e); }
    by.into_iter().map(|(svc, entries)| {
        let last = svc.rsplit('.').next().unwrap_or(&svc);
        ServiceCtx {
            js_class: format!("{}Service", last),
            js_attr:  lower_first(last),
            rpcs: entries.into_iter().map(|e| RpcCtx {
                js_method: lower_first(&e.method),
                rust_fn:   e.rust_fn.clone(),
                res_js:    e.res_type_rust.rsplit("::").next().unwrap_or(&e.res_type_rust).to_string(),
            }).collect(),
        }
    }).collect()
}

fn lower_first(s: &str) -> String {
    let mut c = s.chars();
    match c.next() {
        Some(ch) => ch.to_ascii_lowercase().to_string() + c.as_str(),
        None => String::new(),
    }
}

```markdown
# proffi

Protobuf-defined FFI on top of UniFFI. Declare your library's interface as a
`.proto` `service`, write Rust handlers, and ship typed Python / Kotlin /
JavaScript SDKs over a single `cdylib`.

## Why

Two normally distinct problems collapse into one:

1. **UniFFI's per-language type-mapping surface** shrinks to a single
   byte-vector ABI — every export is `Vec<u8> -> Vec<u8>`.
2. **Languages UniFFI doesn't natively target** (notably JavaScript) become
   reachable via plain C-FFI loaders like `koffi`, because the export shape is
   uniform regardless of how many RPCs you define.

## Quickstart

```bash
cargo new --lib mylib && cd mylib
cargo add proffi prost
cargo add --build proffi-build
mkdir proto && cat > proto/mylib.proto <<'EOF'
syntax = "proto3";
package mylib;
service Greeter { rpc Hello(HelloReq) returns (HelloRes); }
message HelloReq { string name = 1; }
message HelloRes { string msg = 1; }
EOF
```

Add `[lib].crate-type = ["cdylib"]` to your `Cargo.toml`. Then:

```rust
// build.rs
fn main() { proffi_build::compile(&["proto/mylib.proto"], &["proto"]).unwrap(); }
```

```rust
// src/lib.rs
proffi::setup!();
mod proto { include!(concat!(env!("OUT_DIR"), "/mylib.rs")); }

#[proffi::rpc(service = "mylib.Greeter", method = "Hello")]
fn hello(r: proto::HelloReq) -> Result<proto::HelloRes, proffi::Error> {
    Ok(proto::HelloRes { msg: format!("hi {}", r.name) })
}
```

Build and generate:

```bash
cargo build --release
cargo install --path crates/proffi-cli   # one-time, from the proffi repo
proffi generate --lang python --out ./py-sdk
proffi generate --lang kotlin --out ./kt-sdk
proffi generate --lang javascript --out ./js-sdk
```

See `examples/greeter/` for a working end-to-end project with smoke tests
in all three languages.

## Status

Pre-alpha. APIs may change.

## License

Apache-2.0.
```
